# Checkout Direto - Página de Pagamento

Página de finalização de compra desenvolvida em HTML, CSS e JavaScript puro com foco em conversão rápida e design em Dark Mode.

## 🚀 Funcionalidades
* Coleta de Dados Pessoais (Nome Completo e CPF).
* Endereço de Entrega (CEP e Cidade/Estado).
* Design moderno e responsivo otimizado para dispositivos móveis.
* Pronto para integração com gateways de pagamento ou links externos.
